Теория на Metanit
Открыть в pgAdmin
  1. В pgAdmin подключись к своему серверу и создай пустую учебную базу, например sql_notebook.
  2. Открой Query Tool для этой базы. Открой и выполни скачанный файл учебной базы один раз.
  3. Скачай текущий запрос из редактора и открой его в Query Tool. Результаты отобразятся в pgAdmin.
Перенос прогресса

Чтобы продолжить на другом устройстве, скачай файл и загрузи его там. Загрузка заменит местные черновики и отметки.

Практика

Таблицы учебной базы

readers(id, name, city)
books(id, title, genre, price, tags)
loans(id, reader_id, book_id, borrowed_on, returned_on)

У каждой выдачи есть читатель и книга. Если книгу ещё не вернули, returned_on равно NULL. Перед каждым запуском исходные данные восстанавливаются.
