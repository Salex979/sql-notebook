# SQL-тетрадка

Статический тренажёр PostgreSQL. В проекте шесть глав и 49 заданий. PGlite и все его файлы входят в папку vendor. Сборка и сервер базы данных не нужны.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий, например sql-notebook.
2. Загрузите содержимое этой папки в корень ветки main. Файлы index.html и .nojekyll должны лежать в корне, папка vendor — рядом.
3. Откройте Settings → Pages. В Source выберите Deploy from a branch, затем main и /(root). Нажмите Save.
4. После публикации скопируйте адрес из Settings → Pages. Сайт можно открыть по ссылке без аккаунта ChatGPT.

Черновики и прогресс сохраняются в браузере. Чтобы перенести свой прогресс со старого адреса, скачайте JSON через «Перенос прогресса» на старом сайте и загрузите его на новом.

Для запуска локально из этой папки можно выполнить python -m http.server 8000 и открыть http://localhost:8000. Для запуска из ZIP сперва распакуйте архив.
